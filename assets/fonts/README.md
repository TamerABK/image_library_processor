# Britanica fonts

Place the locally licensed font files used by the Illustrator design in this folder before packaging the application.

Expected design family / weights:

- Britanica Thin
- Britanica Regular
- Britanica Bold

Keep font loading centralized in the QML typography layer rather than relying on system-installed fonts.

Suggested local filenames:

```text
Britanica-Thin.ttf
Britanica-Regular.ttf
Britanica-Bold.ttf
```

The font binaries are intentionally not included in this asset package.
